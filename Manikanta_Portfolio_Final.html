Practice projects

Sample scenarios created for learning. These are not verified findings from a live client website.

PRACTICE PROJECT

Login Testing

Practice checking common sign-in scenarios and expected responses.

  • Valid credentials should allow sign-in.
  • Incorrect password should show a clear error.
  • Empty required fields should be validated.
🛒
PRACTICE PROJECT

Shopping Cart Testing

Practice verifying cart updates and totals.

  • Add a product and verify it appears.
  • Remove a product and verify it disappears.
  • Change quantity and check the displayed total.

PRACTICE PROJECT

Test Cases & Bug Reports

Practice writing reproducible, easy-to-understand QA notes.

  • Write preconditions and steps.
  • Record expected and actual results.
  • Suggest severity and priority for review.
